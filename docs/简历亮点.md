# 简历亮点：SmolVLA-Verl

**一句话**：把流匹配 VLA（SmolVLA 0.45B）接入 verl/verl-vla，实现 FlowGRPO 在线强化学习，并搭建「本地采集 → 云端训练 → 回传评估」的训推平台闭环（参考 uniagent-lighting 平台化模式）。

**三个可量化亮点**
1. **算法**：ODE→SDE 边缘保持改造，让 flow-matching 动作头获得闭式 log-density（复现 FlowVLA-RL），实现逐去噪步裁剪 GRPO + KL 正则；LIBERO-Spatial 基线 60.0%，GRPO 目标提升至 60%+。
2. **工程**：在 verl-vla 新增 SmolVLA 模型包（adapter/trainable wrapper/native export）+ flow_grpo 损失；多 runner 并行 rollout、续训、单权重夹覆盖；LIBERO env 接入。
3. **平台**：训推分离（本地 8GB 采集 ↔ 云端 4090 训练），轨迹上传/权重回传脚本化；与 uniagent-lighting 统一「一套平台、两条赛道」。
