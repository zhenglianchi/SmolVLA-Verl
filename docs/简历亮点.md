# 简历亮点：SmolVLA-Verl

**一句话**：把流匹配 VLA（SmolVLA 0.45B）接入 verl/verl-vla，实现 FlowGRPO 在线强化学习，并搭建
「本地采集 → 云端训练 → 回传评估」的训推平台闭环（参考 uniagent-lighting 平台化模式）。

## 可量化亮点

1. **算法落地**：ODE→SDE 边缘保持改造，让 flow-matching 动作头获得闭式 log-density（FlowVLA-RL 路线），
   实现逐去噪步裁剪 GRPO + 固定 base 参考 KL 锚定；LIBERO-Spatial 官方协议（10 任务 × 10 trials）
   **base 63.0% / GRPO 63.0%**，修复正确性 bug 后训练不再退化（旧管道 55% → 63%）。
2. **调试与正确性**：定位并修复批处理重打分破坏 log-prob、组内不同初始场景、终局 mask、episode 均衡
   加权、GRPO 加权分母等一系列会导致「跑一天没效果」的训练正确性问题，并加数值一致性守卫
   （采集/重打分 ratio 偏差 >0.05 直接报错）。
3. **工程与平台**：在 verl-vla 注册 SmolVLA 模型包（adapter/trainable wrapper/native export）+
   flow_grpo 损失；12 实例并行在线 rollout、任务/初始状态轮换、断点续训、单权重夹覆盖、时间截止自动停；
   训推分离（本地采集 ↔ 云端 4090 训练），评估逐任务并行 + 失败重试。

## 诚实表述（面试/简历建议）

- 不要把 63/63 说成「提升」，说「**修复退化 + 持平 base**」更有说服力：先跑通再谈收益。
- 根因（初始状态覆盖 + 数据量 + 100 集噪声）是后续方向的合理叙述：把采集分布对齐评估分布、
  加大每组 rollout、放宽 KL。
